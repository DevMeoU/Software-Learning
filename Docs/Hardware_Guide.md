# Hướng dẫn học phần cứng nhúng

## Các dòng vi điều khiển phổ biến
- STM32 Series (F1/F4/F7)
- ESP32 (WiFi/Bluetooth tích hợp)
- Arduino (Dành cho người mới bắt đầu)

## Development Kit khuyến nghị
1. STM32 Nucleo-64
2. ESP32 DevKitC
3. Arduino Uno R3

## Kỹ năng phần cứng cần thiết:
- Đọc hiểu schematic
- Sử dụng oscilloscope
- Kỹ thuật hàn SMD
- Đo đạc tín hiệu số/analog
