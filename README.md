# Software-Learning

Dự án tổng hợp các tài nguyên học tập về phát triển phần mềm và hệ thống nhúng. 

## Cấu trúc thư mục
- 📁 **ChipSets**: Tài liệu về các dòng vi điều khiển phổ biến (STM32, ESP32, Arduino)
- 📁 **Docs**: Tài liệu học tập, datasheet và application notes
- 📁 **Plan**: Lộ trình học tập chi tiết theo từng chuyên môn
- 📁 **ProgrammingLanguages**: Ví dụ mã nguồn các ngôn ngữ lập trình
- 📁 **Roadmap**: Lộ trình phát triển kỹ năng tổng thể
  - 📁 **Workspace**: Không gian làm việc chính
    - 📂 Code: Các project thực hành theo chủ đề
    - 📂 Docs: Tài liệu kỹ thuật và hướng dẫn
    - 📂 Projects: Dự án tích hợp đa module

## Mục tiêu
- Xây dựng nền tảng vững chắc về lập trình embedded systems
- Thực hành qua các bài tập từ cơ bản đến nâng cao
- Phát triển kỹ năng debug và tối ưu hệ thống nhúng

1. C/C++ căn bản
2. Kiến trúc vi điều khiển
3. Lập trình driver và RTOS
4. Phát triển ứng dụng IoT
